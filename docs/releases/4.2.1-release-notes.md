# Forgeloop 4.2.1

Forgeloop 4.2.1 进一步收紧了 `$spec-standards-review` 的触发授权。双轴审查只在用户明确要求审查一个范围明确的变更集，或活动 Workflow 明确指派、并提供冻结审查范围时启动。

## 明确的触发入口

- 用户明确要求审查某个 PR、分支、固定提交范围或快照时，Skill 可以加载并并行运行 Standards 与 Spec 两个 Reviewer；
- 例如 `$run-initiative` 这类活动 Workflow，在明确指派双轴审查且冻结 Candidate Base/Head 后，仍可自动调用；
- “代码刚实现完”“顺手检查一下”“泛化检查一个文件”、探索、影响分析或调试，不再构成加载该 Skill 的理由。

## 兼容性

- `allow_implicit_invocation` 继续为 `true`：它保留明确 Workflow 的自动调用能力，而不授权主 Agent 自行把实现自检升级为双轴审查；
- 既有的固定点、Base/Head 与快照范围评审，以及 Spec 缺失时的 Standards-only 行为保持不变；
- 不新增 Skill、持久化状态、Tracker 事件或发布运行时。

## 验证范围

本次 4.2.1 由用户明确要求快速发布，未运行测试套件、验证器或本地安装验证。发布内容仅包含上述触发文案、对应集中 UI 元数据、版本号与发布说明的同步更新。
